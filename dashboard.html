FYDP Verification Summary

Git Audit Integrity

The metrics presented in this dashboard are generated directly from the repository's native Git porcelain data on branch dev-backend-final:

  • Line-by-line attribution is calculated via git blame -w -e, accounting for code currently residing in the codebase.
  • Commit volume is extracted using git log --all --numstat across all branch merges.
  • Autogenerated dependencies, lockfiles, and binary assets are filtered out to prevent metric skew.
